# suchabadpanda.github.io

Hosts the public key Tesla's Fleet API needs for the Home Assistant **Tesla Fleet** integration:

`https://suchabadpanda.github.io/.well-known/appspecific/com.tesla.3p.public-key.pem`

Only the *public* key lives here. The private key stays in Home Assistant (`config/tesla_fleet.key`).
`.nojekyll` stops GitHub Pages hiding the `.well-known` folder.
